# NeroAgriculture privacy & telemetry disclosure

NeroAgriculture includes optional, anonymous error reporting so that crashes and bugs caused by the
mod can be found and fixed. This page is the full disclosure required by CurseForge's moderation
rules for mods that use an external analytics/error service, and it documents how the system is
designed to comply with the GDPR (EU) and POPIA (South Africa).

Error reporting is **active in released builds** — NeroAgriculture ships with its own Sentry DSN
configured (`NeroAgricultureTelemetry.DSN`), so reporting starts at launch unless you opt out.

## What is collected (error reporting)

When an error **caused by NeroAgriculture code** occurs, a report is sent to
[Sentry](https://sentry.io) (hosted in the **EU** — `ingest.de.sentry.io`) containing:

- the stack trace of the error and the error message (home-directory paths, which contain your
  operating-system account name, are replaced with a neutral marker before sending, and absolute
  file paths are stripped from stack frames),
- the NeroAgriculture version, the loader (NeoForge / Forge / Fabric), the Minecraft version, and
  whether the game is a client or a dedicated server,
- the operating system name/version and Java version, as collected by the Sentry SDK,
- one of the mod's own configuration values (`growth.controlled_tier`), so a crash that only happens
  at non-default settings can be reproduced,
- the **list of other loaded mods** — their public mod ids and versions only, sorted, and capped at
  the first **300** entries — together with a count, so a crash caused by a mod conflict can be
  identified,
- a session record used for crash-rate statistics (release and environment only), and a random event
  ID generated by Sentry for the individual report.

Reports are de-duplicated per session and hard-capped at **10 events per game session**. Nothing is
stored on disk locally.

## What is NOT collected

- **No IP address** is stored (`sendDefaultPii` is disabled; Sentry discards the sender IP).
- **No username, player UUID, or machine/host name** (`attachServerName` is disabled, and any user
  and server-name fields are cleared from the event before it is sent).
- **No world data, chat, coordinates, inventories, or gameplay analytics** of any kind.
- **No advertising or tracking identifiers** — there is no persistent ID linking reports from the
  same player or machine.
- Errors caused by other mods or by Minecraft itself are filtered out and never sent: an event is
  only sent if its stack trace touches `za.co.neroland.neroagriculture`.

## How to opt out

Set the following in `config/neroagriculture.properties` (created on first launch):

```properties
telemetryEnabled=false
```

This is a client-local switch (not server-synced) and covers everything error reporting sends. The
change takes effect on the next launch; nothing is sent while disabled, and nothing is ever sent
before the config — and therefore your choice — has been loaded.

## Player data stored in the world save

Separately from telemetry, NeroAgriculture stores a small amount of player data in the world save,
keyed by **UUID only** (never a username or display name):

- **Machine ownership** — automation and fabrication machines and powered grow beds may record the
  placing player's UUID so a claims/protection mod can authorise their edits and so progression is
  credited to the machine's owner. This is opt-out via `automation.track_owner = false`, in which
  case no owner is stored at all. The UUID is server-only and never sent to clients.
- **Material milestones / research** — which materials and seeds a player has discovered or
  researched is tracked through Neroland Core's shared progression store, not by this mod directly.

Everything else — the material catalog, greenhouse and tower state, terraformed regions, cycle
phases — is world data with no player attribution.

Ownership data is registered with Neroland Core's shared data-erasure hook
(`data.PlayerDataErasure`), so a single erase request purges a player's NeroAgriculture data
alongside every other Neroland mod. Erasure also writes a UUID tombstone so machines in chunks that
were unloaded at the time drop their owner when those chunks next load; tombstones are pruned after
`privacy.erasure_retention_days` (default 90 days). See
[`wiki/Privacy-and-Erasure.md`](wiki/Privacy-and-Erasure.md) for the operational detail.

## Legal basis and your rights (GDPR / POPIA)

Error reports are processed on the basis of **legitimate interest** (GDPR Art. 6(1)(f); POPIA
s11(1)(f)): keeping the mod functional and crash-free, using the minimum data necessary. They are
engineered to contain no directly identifying personal information, are stored in the EU, and are
retained only for Sentry's standard retention period before automatic deletion.

To exercise any data-subject right (access, deletion, objection), contact
**[info@neroland.co.za](mailto:info@neroland.co.za)** with the approximate date/time of the crash so
the matching event can be located and removed. Sentry acts as a data processor; see the
[Sentry privacy policy](https://sentry.io/privacy/) and
[data processing addendum](https://sentry.io/legal/dpa/).

## Changes to this policy

If a future version of NeroAgriculture ever collects additional data, this page will be updated
**before** that version is released, the change will be called out in the changelog, and the same
opt-out (`telemetryEnabled = false`) will continue to cover everything error reporting sends.
