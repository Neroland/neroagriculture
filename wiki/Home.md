# NeroAgriculture Wiki

Player- and contributor-facing documentation for **NeroAgriculture**, part of the
Neroland ecosystem. Built on **Neroland Core**.

> **Status:** resource-seed economy rework. NeroAgriculture is fully playable with **Neroland Core
> alone**; every other Nero mod adds optional links that are dormant-safe when absent.

## The core loop

NeroAgriculture is a *resource farm*: **craft a resource seed → grow it → harvest the resource**.

1. **Extract** a resource with the **Fragment Extractor** to get **Tier Fragments** (the ladder
   currency) plus a component-tinted **Resource Fragment**.
2. **Upgrade** Tier Fragments up the five-step **Cosmic-ascent ladder** — Territe → Forgite → Orbite →
   Colonite → Voidite — in the **Fragment Infuser** (NeroFlux-powered). Producing each tier opens the
   next native progression gate, so the whole ladder is reachable standalone.
3. **Craft a Prospora Seed** (the base item) and synthesize a **Resource Seed** in the Seed Synthesizer
   from *the real resource + matching Tier Fragments + a Prospora Seed*.
4. **Grow** the Resource Seed on a tier grow bed; harvest **Resource Fragments**; convert **N
   Fragments → the resource**.
5. **Fuse** two resources into an **alloy seed** (e.g. Iron Fragment + Coal → Steel) in the Infuser.

See [Resource-seed economy](Resource-Seed-Economy.md) for the full walkthrough.
